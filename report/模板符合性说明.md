# 附件二模板符合性说明

本版依据用户提供的“附件二---作品设计报告（模板）.docx”调整，共53页。

| 核对项 | 本版处理 |
| --- | --- |
| 匿名评审 | 封面和正文无学校、团队、指导教师或成员姓名；删除此前自加的匿名身份栏和分工表。 |
| 封面 | 直接采用模板副本，保留会徽、竞赛报告名称、题目和中国密码学会落款；填入作品编号和软件设计类别，删除模板提示。 |
| 基本信息表 | 保留模板6行单列表格，含编号、作品题目、作品类别、摘要与五个关键词，整表一页。 |
| 正文内容 | 五个主章对应作品功能与性能说明、设计与实现方案、系统测试与结果、应用前景和结论；原理、运行结果、技术指标及四类测试内容均有对应小节。 |
| 标题调整 | 模板明确允许按作品实际情况增删一级和二级标题；保留必要技术小节、目录和附录。 |
| 页面与编号 | A4、约20mm页边距，沿用模板黑色标题和页眉文字；封面不编号、信息表从1开始，后续连续编号。 |
| 数据 | 52张既有编号表在排除文献序号后数字序列不变；源代码、程序和原实验文件与v25字节一致。 |
| 可编辑稿 | HTML含对应模板字段和完整正文；后续编辑需重新导出、更新目录并复查分页。最终上传采用配对PDF。 |

软件版本仍为interactive-v1.6.3-ui24，本次仅调整报告。构建、功能与浏览器验收回执沿用v24，未将报告排版修订记作软件复测或新性能采样。

本次参考文献修订v26保留模板版式，补入HKDF出处，修正论文页码和文章编号；20条文献按首次引用顺序编号，34处正文引用均可跳转。
