CPU是角色进程启动至采样的整批user+kernel累计；设备另存循环before/after差。峰值为角色进程高水位；当前工作集/Go heap/私有提交分列。绝不除以100冒充单次CPU/峰值，不相加冒充同时峰值。单次归属、P分角色资源、空进程扣除、Linux资源不支持则null+原因。Windows真零保留，ns不是计数分辨率承诺。

吞吐分子为网关真实验收序列化遥测明文字节；TPS为worker观察到的有效远端ACK数；分母为worker首笔发送前至最后control-confirmed观察，含公共日志和轮询。accept/ACK/end-to-end窗口分别保存；有效轮速率算术平均，不改变业务策略换负载。P与T/H认证、记录、日志和进程组织不同，整体差异不全归因ML-KEM。

握手与业务成功分别统计，计划分母固定1000。保存逐次失败、超时、中断及未启动；不拼批、不挑成功、不重试凑成功。中断只保留实际前缀，未启动不算已观察认证失败。资源每批计划100，吞吐每轮200，分母不缩小。成功握手延迟均值/偶数中位均值/P95 nearest-rank从raw重算，保留0ns和计时限制。

生产退出码：0本次成功，2配置/执行，3观测失败，4受控中断，5证据/持久化无效。外层保存真实退出码。完整失败可VALID但不是PASS；所有报告调用正式生产验收器后从raw重算，不从summary反推退出码。不将1000/1000推成未来100%。

## 20设备30分钟live冻结负载

只运行当前Windows EXE，20个本机真实独立Suite2 TCP端点；无race、benchmark、GUI或其他实验并行。授权保持原1小时，队列32/run累计256/内存事件2000/日志20MiB/任务8/导出16不改变。先设20设备5000ms，每设备每5秒自动25℃，不人为持续发控制消耗账本。验证1秒与5秒实际timer对照属于单台专项，不混为正式性能。

从全20实际authenticated起计1800秒。每30秒采集：时间、各设备状态/SID/真实接收数、operations终态/pending、队列/容量/日志水位、可用Go goroutine/内存诊断、Windows进程CPU/工作集/私有提交/句柄时间序列。缺测写null和原因，不从一次内存终值断言泄漏。

第300秒：D001明确断开、确认仅其离线再明确重连新SID。第600秒：D010同样处理。第900秒：受控网关轮换（rotate:GW001:ALL），全旧会话关闭，提交并加载成功，明确重连全部20设备并验证新世代双端认证；绝不旧key重置计数。第1200秒：D020明确断开重连。各阶段至少保存操作前/后状态及真实事件。容许预先声明的维护窗口暂时离线；其他采样点预期全20在线、计数推进且run不变。处理事件异步，不用HTTP200推断通信成功。

保留既有15分钟会话限龄和512条设备记录换钥阈值。默认限龄附近允许最长15秒的真实完整新握手续钥窗口，保存前后SID和双端认证；由于各握手早于统一计时起点，该窗口可能略早于900秒维护或1800秒停止。脚本不自行补偿未知掉线，未能在窗口结束后恢复则FAIL；正常限龄换钥不假装为旧key继续计数，也不写成未经解释的全时在线。5秒采样下单个15分钟会话约180次遥测，不碰512条阈值。

停止前受控导出指定范围；达到内存截断时准确说明省略。1800秒后断开全设备，确认连接/工作者结束，受控退出，核对当前PID终止。再次启动同包新run再正常停止；长期身份保持且不自动恢复吊销。另测配额临界/超限及首中末坏设备，不为持续测试清账本或扩配额。数据仅是live负载稳定性证据，不能当正式握手性能。
