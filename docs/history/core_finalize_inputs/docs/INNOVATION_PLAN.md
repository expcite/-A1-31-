# M6 冻结比较计划

计划 ID：m6-structured-tamper-v1。冻结先于生成器实现与 A/B 执行。候选是测试工具改进，不是新密码算法、防降级功能创新或安全证明。

A 保留 tamper_test.go、downgrade_test.go、kem_implicit_test.go、wire_replay_test.go、channel_test.go 的全部人工 Test 函数，不删减断言。基线名称与文件 SHA-256 由 freeze/baseline.json 固定。现有 M2NEG/M4CASE 已有部分双端状态，不能宣称此前完全没有证据。

B 在 *_test.go 复用真实身份、tamperPair、编码器和真实 T/H 握手，按公开固定规则表生成 39 个有限用例：T/H 各 13 个握手用例，H 的 7 个迁移/KEM 用例，以及 T/H 各 3 个真实记录重放用例。生产密码随机数不固定。每个用例输出 JSON，保留期望/实际阶段、双端 channel、业务未知 null、变异位置、原始/转发公共帧 SHA-256、run_id 和 source hash。中继摘要仅证明观测的发送/转发帧，不冒充端点内部 transcript。记录重放包含正常首条记录对照。

共同规则为选择一致性、offer 绑定、supported 绑定、身份、key_id、随机数、SM2 临时参数、KEM 字段条件、KEM 公钥绑定、KEM 密文绑定、签名、Finished、消息顺序、旧会话记录、跨设备记录、同会话记录重放。角色/版本非法值另列扩展，不抬高共同规则分母。覆盖要求有实际执行结果及对应断言通过，不用数量推导安全性。

正常实现按 A/B、B/A、A/B 顺序各执行三次，单线程用例调度，测试 deadline 2 秒、context 8 秒（A 原夹具不改；原记录测试较长预算如实保留）。成本报告实际进程 wall time（含 Go 启动/编译缓存影响）、Go 包 elapsed、输出 bytes、维护文本行数，不称人工工时节省。三个重复不用于挑最快。

同一组三个隔离缺陷：D1 删除客户端 SigB 验证失败返回；D2 删除客户端 FinishedB 不匹配返回；D3 删除选定套件与可信重算结果不一致返回。复制完整当前文本源码到临时测试目录，在该目录生成 *_test.go 的客户端函数副本，重定向测试中的 Client 调用到副本。原生产 Go 文件不改，禁建 gateway/device/demo，无生产开关。每次跳过目标失败分支输出 M6REACH，用于确认可达。每变体 A/B 各一次，同样规则与真实密码。有效检出必须实际到达删除分支且目标测试断言失败，编译/解析前失败不算检出。未触达写不可达；触达但全部通过写漏检；冗余检查导致阶段改变也单独说明，不等同攻击成功。

诊断比较按实际日志字段计数，不主观打分。随机材料不同，复现要求同 case 定义和失败语义，不要求同摘要。正常 B 再独立执行指定 T_sigB、H_finB、H_implicit 三个用例，核对语义。执行失败、超时和中断全部保留，不自动重试修饰结论。最多三轮正常、三个缺陷和一次复现；真实错误修复时保留原命令并版本化结果，不隐去失败。

M5 原数据、冻结计划、readiness、Demo ZIP 在开工前记 hash，结束再次检查。M6 的 measurement 清单与最终 delivery 清单分开，不能追填 M5。只新增测试/工具/文档，不机械重跑正式 1000 次。全量 Go JSON、原验收 Python 自测、M5 全验收/重算单独执行。race、独立 SM2 交换、OpenSSL SKIP、Linux 未测保持原证据状态。

停止条件：实际 A/B 结果可复核、材料生成且引用一致、完整回归、M5/Demo 未改、ZIP manifest 验证。无优势亦交付真实结果，完成 M6 即停止。
