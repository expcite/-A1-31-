# EdgeHybrid B+ 一页快速入门

1. 解压新的Windows软件文件夹，双击“启动1设备.cmd”或“启动20设备.cmd”。保持启动窗口，输入该窗口的一次口令授权；口令不在网址里。
2. 默认进入“通信工作台”，选择目标设备，点击“连接当前设备”。等待“已认证在线”，HTTP受理不是握手成功。
3. 左卡输入26.3或28.7℃，点击“发送温度”。看本次已提交值和网关确认；继续修改输入不会改变旧回执。
4. 在次级设置区“暂停采样”，设备保持在线。右卡设置1或5秒，点击“设置上报间隔”，查看设备处理和真实确认；未确认可能已执行，软件不会自动重发。
5. 需要答辩讲解时点击“开启演示引导”。下一步仅定位；G3需明确换钥和新SID验证，现有接口不能独立归因时会写证据不足。G4锁定范围后明确导出，下载文件另核对哈希。
6. 设备与连接可批量连接、筛选、查看稳定详情；密钥与策略的维护需输入确认文字，网关维护影响全部设备且不自动重连。实验需先明确断开全部live设备，再重新读取状态并独立点击开始。
7. 记录与证据默认不含温度载荷，范围固定；过期、淘汰或错误run必须重新选范围。历史测量属于原版本，保留0ns和失败。
8. 暂停采样、断开设备、退出软件是三件事。关闭网页不会退出；侧栏退出需确认，或使用原“停止交互平台.cmd”。状态过期仍可在有效授权下明确停止；无法确认则看启动窗口/停止脚本。

用户运行不依赖Go、Python、Node、Java或CDN。设备和网关必须是同版SM2确认实现。软件是本机模拟设备的真实安全TCP原型，不是硬件认证或密码合规认证。
