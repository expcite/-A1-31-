# EdgeHybrid B+ 用户与复现手册

本轮产品版本 interactive-v1.4-bplus1，前端 BPLUS-UI-v1.0；后端密码和安全约束继承SM2确认版。当前实际构建来源以build_info.json及源码清单为准。[一页快速入门](BPLUS_QUICK_START.md)。

## 普通工作台与引导

授权后默认工作台。五项导航和帮助均可直接使用，演示引导关闭时不隐藏核心能力。刷新/前进/后退恢复受控页面，只读取当前run，不连接设备或重发操作。各设备温度/周期/模拟采样源草稿仅保存在当前标签页内存，切页面保持，刷新可以清空；不保存明文载荷或令牌。

双向卡分别显示草稿、提交快照、服务端状态。queued等待发送；writing开始写出；written已写出等待确认；confirmed已确认；unconfirmed未确认、可能已执行；late_confirmed迟到确认；failed失败；cancelled已取消。HTTP响应丢失是前端提交结果未知，不伪造后端失败，不自动生成新意图重试。仅取得真实operation_id后可关联记录。操作详情仅queued可尝试后端取消，竞争时由后端拒绝；已写出不保证撤销。

G1读取当前目标认证在线条件，进入时已在线明确写已有连接。G2只认可本次引导关联的手动温度和控制操作，不累计历史或自动采样。G3观察请求受理、新SID和验证消息，但当前API缺少本次手动rekey独立因果标识，保留证据不足。G4锁定当前目标事件范围，经明确导出和符合selection的回执才说生成；点击摘要不等于导出，生成不等于磁盘保存。跨设备/run重新建立上下文，旧引用只可历史查看。刷新后重新核验公开引用，淘汰时提示无法核验。

## 设备、维护与实验

设备数量来自既有可信设备池。批量连接显示逐设备accepted/rejected及实际在线状态，accepted不是握手完成。更多菜单中的断开和完整会话换钥与暂停采样不同。设备身份轮换、吊销、退役、传统/混合最低策略在密钥与策略中维护，精确确认文字保持原契约。网关长期维护明确影响全部设备，注册表提交、旧会话关闭、准入重新开放、加载错误和清理待处理分开显示；不自动重连或恢复吊销。

安全实验室仅原固定m6_rules、bench_T、bench_H、pbench任务；前置条件包括新鲜状态、已读取的任务状态、无在线/连接中设备、无互斥任务以及额度。确认断开后只重读状态，需要另一次明确启动。显示真实exit_code、receipt_status和部分输出；任务完成不直接代表规则全通过，3次smoke不代表正式性能实验。

## 有界记录和来源

当前记录只表示run的最近2000事件；公共日志最多20MiB，筛选/分页/导出共用固定范围。背景轮询不更新范围，手动“更新记录范围”同时更新完整快照、候选筛选、表格、分页和导出；保留有效或明确失效选择，不悄悄切到全部。JSON/CSV/HTML下载回执保留selection、事件数、字节及SHA；空导出不沿用旧文件。默认剔除温度载荷，明确包含须原include_simulated_payload确认。

历史测量单独查看原平台、run和源哈希。0ns不删除；1000/1000不推未来100%；进程批次CPU/内存不冒充单次握手；T/H/P整体差异不全部归因ML-KEM。历史M6改进为审计信息更完整，覆盖和检出相同。历史race/独立交换/OpenSSL记录按实际执行及来源说明，不将历史pending统一改PASS，也不把旧14组核心当标准S1/S2对照。

## 状态、授权和故障

state读取3秒超时、3.5秒过期且独立每秒检测，build/session慢不阻止过期提示；meta来源不明写未知。过期时显示上次观测并禁用依赖当前状态的写动作。恢复后按设备在线、生命周期、维护与忙碌分别判断，不全局解锁。有效授权下保留安全停止/退出；不能确认退出结果时使用原停止入口。授权一小时有效期不自动续期，失效后清理业务显示和待提交上下文。

queue_full：等待32项待发队列消化，勿连续重试。operation_limit：本run累计256项，先导出后停止并另启新run，换钥不清账本。任务8项/导出16份分别限制，不能为了演示绕过。401也可能是防伪不匹配，按原本机流程排查，不清除持久身份。未知状态/时间字段写未识别或未观测，不补0和false。
