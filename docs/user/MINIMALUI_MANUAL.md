# 一页快速入门

1. 解压软件文件夹，双击启动1设备.cmd。输入窗口一次口令授权；不要把口令放URL或导出。
2. 工作台选D001，未连接时明确点击连接；等待“已认证在线”。
3. “发送温度”输入26.3，点击发送。按钮旁查看网关本次真实接收回执；编辑28.7不改变26.3的提交记录。
4. “设置间隔”选择5秒或自定义0.1～60秒，明确提交。只有设备真实处理且网关验证ACK才显示确认。
5. “采样与会话设置”可暂停自动采样、修改本机模拟源、断开或完整会话换钥。暂停保持连接，仍能主动控制；断开结束连接；关闭网页不会停止软件。
6. 记录页先明确更新固定范围，筛选设备，更多筛选查看观察端/阶段。当前条件和范围始终可见。导出格式在单层展开菜单；生成≠文件已存磁盘。
7. 当前运行/停止中可安全停止设备或退出软件。不能读到退出结果时用随包停止.cmd；重新启动产生新run。不要为重试清除身份或计数器。

# 完整使用说明

四主入口：工作台、设备、记录、实验。管理展开后有设备身份与迁移、网关维护；帮助含说明与演示引导。旧#communication/#devices/#keys/#lab/#logs/#help链接保持有效。切标签、切页面、刷新不发业务POST；草稿仅内存，刷新清空，切页面保留。各run/设备/动作独立。

工作台的手动值、自动采样源、网关最近接收值分别展示。HTTP接受只代表排队；queued、writing、written、confirmed、unconfirmed、late_confirmed、failed、cancelled保持不同语义。超时可能已经执行，不自动重发。技术ID/时间/公开JSON在唯一详情侧面板，只有尚未写出项可请求取消；后端竞争时可拒绝。

G3：帮助开启引导→G3→采样与会话设置→完整会话换钥。按精确文字确认，等待本次rekey_id的新SID双端准入，再回工作台手动发送验证温度。仅本次run/设备/旧SID/新SID和之后的真实验证确认匹配，才完成本步。没有标识的历史请求、自动换钥、失败、未知或淘汰记录不会凑成通过。此回执为本机可审计观察，不是密码认证。

设备的批量操作按全部设备逐一尝试；结果摘要与当前在线观测分别显示，逐设备详情失败优先。管理选择一个对象再维护，精确危险确认不可省略。网关维护影响全部相关设备，注册表提交、关闭、重新准入、加载错误、清理分别观测。不会恢复吊销身份或自动重连。长期身份轮换≠完整会话换钥。

实验只使用原固定m6_rules、bench_T、bench_H、pbench白名单，与live互斥。明确断开之后需要再次明确开始；真实exit_code和receipt_status分开，smoke不替代正式性能。

日志最近2000条、公共文件20MiB，上限不扩大；背景轮询不改变固定分页。显式更新同时重建未筛选候选、表格、范围和导出；失效筛选显示无匹配，不悄悄扩大为全部。载荷默认剔除，包含需精确确认。旧M5数据仍是旧测量版本，0ns保留，1000/1000不推未来100%，批次CPU/峰值不是单次握手，T/H/P整体差异不全归因ML-KEM。

错误处理：queue_full等待32项队列消化；operation_limit累计256项需导出后新运行，换钥不清账本；rekey_limit独立256换钥回执需导出后新运行；任务8项、导出16份分别有限。授权过期需原一次口令流程，不清Cookie或持久身份冒充解决。状态3秒读取超时/3.5秒过期，恢复按对象重新检查。未知观测不补0或false。

开发入口：[API](../INTERACTIVE_API.md)、[后端构建测试](../BACKEND_BUILD_AND_VERIFY.md)。构建scripts/backend_build.py；普通Go/Windows race/独立组件对照范围以实际本轮与历史回执区分。前端测试保留旧BPlus/F07并新增G3；真实截图、命令、退出码在本轮审查包。无真人试用不编造满意度和上手时间；不能执行的200%缩放单列，窄视口不等价。
