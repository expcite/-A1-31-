# EdgeHybrid Windows 一键演示使用说明

这是本地竞赛演示原型：真实 Suite2（SM2/SM3/SM4 + ML-KEM-768）握手和加密记录，业务是模拟遥测。未通过外部安全审计，正式性能实验未完成，不是园区部署版。

## 启动与选择

1. 将 EdgeHybrid_Demo_Windows.zip **完整解压**到一个可读目录。路径可以包含中文和空格，不要直接在 ZIP 预览里启动。
2. 双击 **EdgeHybridDemo.exe**，默认启动 1 台混合设备。也可双击 **启动1台设备.cmd**。
3. 要看 20 台，先停止当前演示，再双击 **启动20台设备.cmd**。
4. 启动程序自动打开默认浏览器；地址为本次自动分配的 `http://127.0.0.1:端口/`。启动窗口同时打印 PAGE_URL；默认浏览器未配置时，可复制地址手动打开。

用户运行不需要 Go、Python、Bash、Node 或 go run。只需要 Windows x64、可写用户数据目录，以及一个可用浏览器。程序未签名；实际仅在报告所列开发机验证，不能宣称覆盖所有 Windows 电脑。若系统安全提示阻止运行，不修改系统策略或绕过提示。

## 看懂页面

每台设备只运行 **本轮 3 笔**遥测→控制→真实 ACK 验证的业务；不自动重连或无限刷成功数。各设备使用独立身份和 SID，实际 Suite2/KEM 信息来自真实建链事件。

- 连接中：设备工作者尚未建链。
- 通信中：本次建链/业务正在进行。
- 已完成本轮：设备工作者已经返回。网关的接受、发送和确认分别计数，不能把本地 ACK 写出当远端确认。
- 失败：显示真实错误及阶段。固定 `19+1` 自测异常为 D020，本地信任预检失败，**没有发起远端握手**；其他 19 台继续运行。
- 已停止：停止程序完成取消、等待、关闭日志。关闭网页不会停止程序。

当前在线数与本次累计建链数分开；已完成并断开的会话为 0 在线。页面只使用内存中的本次事件，不读取历史 results。页面失去连接时保留最后缓存并标“状态不可确认”，不能把缓存当在线状态。

## 停止、再次启动与异常

回到启动窗口按 **Enter** 或 **Ctrl+C**；也可双击 **停止演示.cmd**，它只向同一解压包的演示实例发送本机停止事件。停止窗口不是网页控制接口。等待启动窗口打印“已停止”。之后可再次启动，新运行使用新 run_id、新测试身份。

重复启动会提示“本包演示已经运行”，不会覆盖当前运行。不同解压目录有明确独立实例，各停止入口对应自身包目录。端口默认自动分配；验证用固定端口发生冲突时提示启动失败。窗口启动失败会保留提示。

程序最长保留状态页 10 分钟，之后受控停止。异常强制结束可能保留该次 private 目录；下次启动会提示上次未记录正常退出，使用全新运行，不把旧业务当实时状态，也不自动删除旧运行材料。浏览器会标记已断开。

## 日志与测试身份

启动窗口的 **LOG_DIR** 和页面“可分享的本次公共日志”给出完整路径，默认形如：

`%LOCALAPPDATA%\EdgeHybridDemo\<包目录标识>\runs\<run_id>\logs`

可分享该 **logs** 目录：gateway.jsonl、device.jsonl 是原程序公开事件；events.jsonl 带本机采集来源；lifecycle.jsonl 记录真实工作者结果；manifest.json 记录本次配置，completed.json/final_state.json 是完成/停止状态。

新测试身份位于同一独立数据根目录的 **private\<run_id>**，正常停止后只清理本次目录。不要分享 private；不在分发包预放私钥，也不读取现有工程 runtime。Windows 文件 ACL 未由本程序额外加固；继承用户目录权限，不宣称已经实现私钥 ACL 隔离。程序不申请管理员权限、不调整系统策略、不上传远端。
